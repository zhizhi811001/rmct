# RMCT GitHub Pages Vocabulary Portal

Static, dependency-free portal generated from `RMCT_v2.0_Standalone.ttl`.

## Publish under your existing repository

1. Copy the contents of this folder into the repository's `docs/` directory.
2. Commit and push to the `main` branch.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Choose **main** and **/docs**, then save.
5. The site will appear at `https://zhizhi811001.github.io/rmct/`.

## Included

- searchable vocabulary browser
- eight facet entry cards
- concept detail pages driven by URL hashes
- definitions, scope notes, broader/narrower concepts and alternative labels
- downloadable Turtle source

Generated inventory: 381 concepts; 8 top concepts; 77 direct categories; 236 alternative labels.
